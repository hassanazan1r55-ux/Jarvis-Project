> **JARVIS** is a powerful, voice-controlled AI assistant that helps you automate daily tasks on your PC. Just say the wake word and command, and JARVIS will handle the rest! 🤖

---

## ✨ Features

### 🎯 Core Features
- 🎤 **Voice Recognition** - Hands-free control with speech-to-text
- 🧠 **AI Integration** - Powered by OpenRouter AI (GPT, Claude, etc.)
- ⚡ **Ultra-Fast** - Optimized for instant response
- 🔧 **Custom Wake Word** - Choose your own wake word (`ai`, `jar`, `jay`, etc.)
- 🌐 **Web Automation** - Open websites, search Google, play YouTube
- 📂 **App Control** - Open/close applications
- 🖥️ **System Control** - Time, date, battery status, screenshots
- 💬 **Continuous Mode** - Natural conversation without repeating wake word

### 🎮 Available Commands

| Category | Commands | Example |
|----------|----------|---------|
| **System** | time, date, status | `ai time` |
| **Apps** | open, close | `ai open chrome` |
| **Web** | search, youtube | `ai search Python` |
| **Fun** | joke, motivate | `ai joke` |
| **Utility** | screenshot, lock | `ai screenshot` |
| **AI** | anything else | `ai who is Einstein` |

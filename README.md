# Jarvis-Project# 🤖 JARVIS Assistant v2.0

Your personal desktop assistant built in Python.

## 🚀 Features
- Voice & Text commands
- Open/Close applications
- System monitoring (Battery, CPU, RAM)
- Web search (Google, YouTube)
- Screenshots
- AI responses (Jokes, Quotes, Greetings)
- Shutdown/Restart/Lock system
